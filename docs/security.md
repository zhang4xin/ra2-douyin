# 安全与合规检查清单（security）

> 来源：多部门头脑风暴（安全 / 合规 / 平台工程）结论。
> 目标：单机版的安全加固与上架合规。P0 = 发布硬门槛。

## 总体结论

技术上 P0 项（资源离线化、WASM 分包、遥测禁用、http 扫描、适配层审计）可在数天内完成大部分；
**真正的卡点是版权授权与版号/备案**——它们决定项目"能不能上架"，其余只是"怎么上架更稳"。

## P0（发布前必须关闭）

- [ ] **版权授权**：取得北京瑞得哈希（RA2WEB）书面授权，或明确"仅内测不上架"；评估 EA 红警 IP/商标风险（标题不出现"红色警戒"等商标词）。
- [ ] **版号/备案**：免费无内购 = 小游戏备案；含内购 = 版号。向抖音开放平台确认当期要求。
- [ ] 游戏内显著保留 `RA2WEB / 网页红井 / 红色井界` 名称之一。
- [ ] **遥测禁用**：`config.ini [Sentry]` 已置空 ✅；发布前 grep 确认无 `sentry/telemetry/incident` 外发。
- [ ] **资源 hash 固化**：当前发布版资源 hash 固化进分包 + manifest 校验（构建期流水线）。
- [ ] **ffmpeg-core 本地化**：移除 `unpkg.com` 远程依赖（供应链投毒面）。
- [ ] 无远程 JS 动态加载（构建期扫描门禁）。
- [ ] 内置 MOD 固化，关闭 mod 在线下载入口。
- [ ] 构建扫描无 `http://` 实际加载。
- [ ] 适配层最小 API 审计 + `eval/Function` 调用点清单（不实现 innerHTML 等富 DOM，减少动态执行面）。
- [ ] 主包 ≤4MB、总包 ≤24MB。

## P1（发布前建议清零）

- [ ] 存档 HMAC-SHA256 校验 + 原子写（临时文件 rename）+ 双副本 + 值域校验（金钱/血量非负）。
- [ ] 不调用 `tt.login` / `tt.getUserInfo`（单机版无需用户身份）。
- [ ] 真机抓包验证：启动/开局/退出**零外连**（白名单之外的域一律不通）。
- [ ] debug 开关全关（`debugGameState` / `debugLogging`），对外错误信息脱敏。
- [ ] 商店标题/描述去除"联机对战/红色警戒"表述，改为单机描述。
- [ ] 内容审核：无纳粹/法西斯特、无真实历史人物、无血腥写实。
- [ ] 域名白名单在抖音后台配置（清单见 `build-config.json.whitelistDomains`）。
- [ ] 隐私政策：无服务端版写"仅本地存储、不收集个人信息、无第三方 SDK 传输"。
- [ ] 提审包无 `touristappid` / `127.0.0.1` / 测试域名残留。

## P2（维护期处理）

- [ ] 核心 JS 构建期混淆（不改压缩产物，在打包链做）。
- [ ] 自持 CDN 时 URL 鉴权签名 + Referer 白名单（防盗链）。
- [ ] 存档对称加密（防君子不防小人，明确不做防作弊承诺）。
- [ ] 发布产物 hash 签名 + git 签名 tag + SBOM。
- [ ] 供应链定期比对：CDN 内容 hash 与基线 diff。

## 风险提示（未完成部分）

1. **第三方 CDN 依赖**：`stdres.wangerhuoda.cn` / `gmap.wangerhuoda.cn` / `mod.btfs.cn` 等任一失效/被劫持 = 游戏不可玩或内容被投毒。→ 目标：资源离线固化进分包，白名单趋近为零。
2. **小游戏包可被解包**：`werhd.min.js` 与资源可被提取再分发，防不住；保护重心放在授权与法务，不做"绝对保密"承诺。
3. **纯客户端存档可被改**：只能防损坏，不能防作弊；不在客户端放置付费解锁等高价值内容。
