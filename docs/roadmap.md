# 移植路线图（roadmap）

> 汇总多部门头脑风暴（产品 / 工程 / 测试 / 设计 / 安全）形成的落地计划。
> 原则：**M0→M1→M2→M3 逐门禁放行**，上一里程碑未过验收不得进入下一阶段。

## MVP 定义

**第一版必须能：进主菜单 → 开一场遭遇战（简单 AI）→ 触控可操作 → 打完出胜负结算。**
非目标（公开拒绝）：联机/天梯、商城/内购、账号体系、完整战役关卡（V1.1）、云存档、PC 键鼠体验完整保真、追赶上游新版本。

## 里程碑

### M0 骨架验证（当前阶段，1-2 周）
目标：工程骨架在开发者工具可跑，仓库可协作。
- [x] 抖音工程骨架（game.js/game.json/project.config.json）
- [x] 联机禁用、遥测禁用、品牌修正
- [x] 适配层基础 + 质量门禁 + 冒烟测试
- [ ] **Spike：WASM（7zz.wasm / ffmpeg）在抖音运行时可行性** → 更新 ADR-0003
- [ ] 仓库瘦身：只留 0.83.4 版本目录（按 ADR-0002）
- [ ] CONTRIBUTING / ADR 落档 ✅（已就绪，随库推送）
- 验收：开发者工具导入显示占位画面不白屏不崩溃；`npm test` 全绿。

### M1 引擎跑通（2-4 周，关键路径，最高风险）
目标：引擎在小游戏运行时运行，主菜单出现。
- `scripts/build.js`：esbuild 把 lib 链 + `werhd.min.js` 打包为 CJS 单包（依赖 ADR-0003 WASM 结论）。
- 迷你 DOM 树（React 挂载面）+ 事件系统 + `ScriptRegistry`（脚本加载拦截）。
- Image / Audio / 网络 / 文件系统桥；`new Worker` 主线程仿真优先。
- 验收：开发者工具/真机出现可操作主菜单、无致命报错。

### M2 触控可玩（2-3 周）
目标：遭遇战可开打并打完，触控操作闭环。
- 渲染接管：主 canvas = `tt.getGameCanvas()`；触控->事件注入闭环（`EventSynthesizer` 已就绪）。
- 叠加层 HUD：命令条、编队浮条、快捷按钮、虚拟键盘 HUD（按 `docs/mobile-controls.md`）。
- 验收：一局遭遇战完整打完→胜负结算，无闪退；触控专项指标达标。

### M3 打磨发布（2-3 周）
目标：可上架。
- 分包 + CDN 资源落盘 + manifest 校验；包体 ≤4MB/24MB。
- 性能基准（冷启动 ≤5s、中端 30fps）、真机测试矩阵、弱网降级。
- 合规材料：版权授权确认、版号/备案、域名白名单、隐私政策（`docs/security.md`）。
- 验收：通过抖音审核，主流机型流畅。

## 分工建议（2-3 名员工）

| 员工 | 主攻 |
|---|---|
| A | 适配层（DOM/事件/网络桥）+ 引擎打包链 |
| B | 触控 HUD + 手势调优 + 真机测试矩阵 |
| C | 构建/资源管线 + 安全合规 + 版本管理 |

## 关键风险

| 风险 | 等级 | 缓解 |
|---|---|---|
| WASM 不可用/受限 | 高 | M0 Spike + ADR-0003 降级方案（CDN 预解压） |
| 主包超限 | 高 | 分包 + 远程资源 + 裁剪（同一件事：资源瘦身） |
| 版权授权/版号 | 高 | M3 前置办理；未授权只内测不上架 |
| 多人同改 assets | 高 | ADR-0002 瘦身 + 只读规则 |
| 触控交互低估 | 中 | M2 独立里程碑 + 先做输入原型 |
| 上游版本漂移 | 中 | 锁 0.83.4 + `-dy` 后缀 |

## 总工期预估

约 7-12 周（2-3 个月），2-3 名员工。DOM 适配层与 UI 绘制器是最大不确定性，建议先拿到 M1 的"进图可操作"里程碑再决定 UI 绘制投入。
