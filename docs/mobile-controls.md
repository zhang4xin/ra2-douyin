# 手机端触控操作方案（mobile-controls）

> 来源：多部门头脑风暴（游戏设计 / UX / 移动开发）结论。
> 目标：让鼠标键盘 RTS 在手机触屏上"打得动、打得爽"。
> 对应实现：`adapter/input/EventSynthesizer.js`（手势->事件合成，已落地基础版）。

## 核心选型：Tap 默认化 + 双指镜头 + 命令条 + 编队浮条

| PC 操作 | 触屏方案 | 状态 |
|---|---|---|
| 左键单击 | 单击（<250ms 位移<10px） | ✅ 已实现 |
| 左键框选 | 单击拖拽 | ✅ 已实现 |
| 双击全选同类 | 双击 | ✅ 已实现 |
| 右键指令 | 长按 0.4s（+震动反馈） | ✅ 已实现（`contextmenu` button=2） |
| 滚轮缩放 | 双指捏合 | ✅ 已实现（`wheel`） |
| 滚屏 / 镜头平移 | 双指拖动 | ✅ 已实现（中键 button=1） |
| 编队 Ctrl+1~6 | 编队浮条（Phase 2） | 🚧 |
| 全选/空闲单位/基地/最近事件（Ctrl+A/N/H/空格） | 快捷按钮（Phase 2） | 🚧 |
| Q/W/E/A/S 等快捷键 | 命令条按钮（Phase 2） | 🚧 |
| 暂停 | 常驻暂停按钮（Phase 2） | 🚧 |

**降疲劳关键**：已选单位时"单击空地 = 移动"（高频右键默认化），把最常用的移动指令从"长按等待 0.4s"降到"即点即走"（Phase 2，需引擎选中状态可读性 Spike）。

## 手势判定参数（可调，真机调优用）

| 参数 | 默认 | 说明 |
|---|---|---|
| tapMaxMs | 250ms | 判定为"单击"的最长按下时间 |
| tapMaxMove | 10px | 判定为"单击"的最大位移 |
| dblTapMaxMs | 300ms | 双击间隔 |
| longPressMs | 500ms | 长按=右键的时长 |
| dragThreshold | 10px | 进入"拖动框选"的位移阈值 |
| moveIntervalMs | 16ms | 拖动时 mousemove 插值补帧间隔 |

## 触屏 UI 布局（Phase 2，叠加层 HUD）

- 锁定横屏（`game.json` 已 `landscape`）。
- 引擎画布固定 1024x768 放大适配（`ViewportTransform` letterbox），交互层按真机分辨率叠加。
- 右下命令条（攻击/移动/停止/部署/驻守/出售，按钮 ≥44px≈88rpx）。
- 右侧建筑栏 + 顶部 Tab（防御/基建/兵种/其他）。
- 左上小地图放大（≥100px 逻辑像素），可点可拖。
- 顶部资源条（金钱/电力/时间）+ 暂停/菜单按钮。
- 安全区适配：避开刘海/挖孔/Home 条。

## 上手引导（抖音首 30 秒）

1. 首启默认进"快速遭遇战"：小地图 + 简单 AI + 满资源，跳过菜单。
2. 3 条非阻断式箭头引导：点击选中 → 点击移动 → 点击攻击。
3. 关卡化教程（5 关 × 1-2 分钟），每关只教一个新动词。
4. 首胜保底：第 1 关 AI 不攻击，100% 首胜。
5. 自动暂停：切后台/来电自动暂停。

## 单机内容取舍

- 默认 MOD：共和国之辉（`forcedModId=gonghui`）✅ 保留。
- 美苏阵营补丁（97KB）✅ 推荐（简化科技树，降触屏 UI 密度）。
- 红警4（2MB）⚠️ 可选（实验室）。
- 焦土（136MB）❌ 裁掉（包体 + 触屏承载不了）。
- 地图：优先 8-10 张 2-4 人小图，单局目标 3-8 分钟。

## 验收指标（触控专项，Phase 2/3）

- 点击命中率 ≥95%（热区 ≥44x44pt，间距 ≥8pt）。
- 10 分钟标准局误操作 ≤2 次。
- 双指捏合期间零 click/框选泄漏（事件日志验证）。
- 返回/退出误触发率 = 0（必须有二次确认或自动保存）。
- 低帧（20fps）下操作到响应 ≤150ms。
