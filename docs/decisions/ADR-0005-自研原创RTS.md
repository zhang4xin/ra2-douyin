# ADR-0005：放弃红警引擎移植，转向自研原创 RTS

- 状态：已接受（2026-08）
- 背景：原目标为把 RA2WEB/网页红警 移植为抖音小游戏单机版，在 M0 骨架（工程/适配层/触控链路）就绪后，决定转向。

## 决策

**不再移植 RA2WEB 引擎，改为在既有工程骨架上自研一款原创即时战略小游戏（暂名「钢铁前线」）**。玩法逻辑参考红警（建基地、造兵、对推），但代码与素材全部自研，不使用任何红警代码/素材/名称。

## 理由

1. **版权与上架风险**：原 README 明确要求保留品牌名、禁商用、需版权方书面授权，且上架属公开分发需提前确认版号/备案。自研原创游戏无此负担，可正常走小游戏提审流程。
2. **引擎移植技术障碍**：上游引擎是 Vite 产物（ESM + 顶层 `await`），抖音开发者工具按 CommonJS 编译整包必然失败；已用 `packOptions.ignore` 规避（Phase 0 不需引擎），但治标不治本，后续每个 Phase 都要与编译环境搏斗。
3. **更快出可玩版本**：自研逻辑可用纯 JS 快速迭代，且有 Node 单测与无头渲染冒烟测试兜底，比攻破 700MB 引擎的 DOM/资源/文件系统适配链快得多。

## 沿用与舍弃

- 沿用：`adapter/`（触控→鼠标/wheel 合成器、视口、全局面——已在开发者工具验证）、工程骨架（game.js/game.json/project.config.json）、质量门禁（test/audit-dom/check-size/smoke-render/format）。
- 舍弃：`assets/`、`runtime/`、`res/`、`lib/` 引擎与网页残留（已删除，git 历史可回滚）；`spike/wasm-load`（7z WASM 验证，已达成历史使命，删除）。
- 历史资料：ADR-0001~0004、roadmap.md、mobile-controls.md 等仍保留，作为旧方案的记录。

## 影响

- 品牌：新游戏不使用红警相关名称，避免混淆与侵权。
- 架构：新增 `game/` 目录，纯逻辑（可单测）与渲染/输入分离。
- 包体：删除引擎后工程 <1MB，远超平台限制。
