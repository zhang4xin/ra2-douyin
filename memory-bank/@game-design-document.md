# 游戏设计文档（单机版 · 抖音小游戏）

> 本文档是「Always 先读」文档之一。动手写任何代码前，先完整阅读本文件。
> 一句话目标：**把网页红井（RA2WEB）的联机平台裁剪成可在抖音触屏上玩通的单机遭遇战。**

## 一句话目标 + 非目标

- 目标：横屏抖音小游戏，用户能在触屏上完成「进主菜单 → 开遭遇战 → 操作部队 → 打完结算」。
- 非目标（明确拒绝）：联机/天梯/房间、商城内购、账号体系、完整 16 关战役（V1.1）、云存档、PC 键鼠体验 100% 保真、追逐上游新版本。

## 内容范围

- 默认 MOD：共和国之辉（`forcedModId=gonghui`）——保留。
- 美苏阵营补丁（~97KB）——推荐（简化科技树，降触屏 UI 密度）。
- 红警4（2MB）——可选（实验室）。
- 焦土（136MB）——裁掉（包体与触屏承载不了）。
- 地图：优先 8-10 张 2-4 人小图，单局目标 3-8 分钟。

## 操作方案（触屏）

核心选型：**Tap 默认化 + 双指镜头 + 命令条 + 编队浮条**。

| PC 操作 | 触屏方案 | 状态 |
|---|---|---|
| 左键单击 | 单击（<250ms 位移<10px） | ✅ 已实现 |
| 左键框选 | 单击拖拽 | ✅ 已实现 |
| 双击全选同类 | 双击 | ✅ 已实现 |
| 右键指令 | 长按 0.4s（+震动） | ✅ 已实现 |
| 滚轮缩放 | 双指捏合（wheel deltaY） | ✅ 已实现 |
| 滚屏/镜头平移 | 双指拖动（中键） | 🚧 Phase 2 |
| 编队 Ctrl+1~6 / 快捷键 / 暂停 | 浮条 / 命令条 / 暂停按钮 | 🚧 Phase 2 |

降疲劳关键（Phase 2）：已选单位时「单击空地 = 移动」，把高频右键从「长按等 0.4s」降为「即点即走」。

详见 `docs/mobile-controls.md`（完整参数表与真机验收指标）。

## 包体与运行时约束（硬限制）

- 主包 ≤4MB，总包 ≤24MB，独立分包 ≤4MB。
- 当前全仓 ~635MB（含 92 个历史版本目录），仅保留 0.83.4 一套（见 ADR-0002）。
- 运行环境：抖音小游戏运行时无 DOM/BOM，JS 为 CommonJS，WASM 可行性待 M0 Spike（ADR-0003）。

## 品牌与许可红线（不可谈判）

- 必须保留名称之一：`RA2WEB` / `网页红井` / `红色井界`。
- 禁止商用（除非版权方书面授权）；上架需授权 + 版号/备案 + 域名白名单。
- 完整清单见 `docs/security.md`。

## MVP 验收（= M2 里程碑）

进主菜单 → 开一场遭遇战（简单 AI）→ 触控可完整操作 → 打完出胜负结算，无闪退。
